# Portfolio

Personal portfolio website of Satvik Tiwari.

Live site: [sxtvik.site](https://sxtvik.site)

## Stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS v4
- shadcn/ui
- TypeScript

## Features

- Light and dark themes
- Responsive layout
- GitHub contribution graph
- Spam-protected email and phone
